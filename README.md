## 👨‍💻 About me

I'm a backend developer focused on **Go**. I design and build APIs, microservices and data pipelines that are fast, observable and easy to maintain.

- ⚙️ **What I do:** REST & gRPC APIs, microservices, event-driven systems with message brokers, database design and query optimization
- 📈 **What I care about:** clean architecture, test coverage, performance, and code that the next developer can understand
- 🚚 **How I ship:** containerized services orchestrated with Kubernetes and Docker Swarm, CI/CD pipelines, and Linux-based deployments
- 🔐 **How I run it:** service discovery and configuration with Consul, secrets management with HashiCorp Vault, monitoring and tracing with Prometheus, Grafana and OpenTelemetry

## 🧠 Engineering practices <!-- NEW section -->

- **Architecture:** microservices, Clean / Hexagonal Architecture, DDD, event-driven design, CQRS
- **Reliability:** idempotency, retries & circuit breakers, transactional outbox, graceful shutdown, rate limiting
- **Data:** schema design, indexing & query optimization, migrations, caching strategies, transactions & isolation levels
- **Concurrency:** goroutines, channels, worker pools, `context` propagation, race-free code
- **Quality:** unit & integration tests, table-driven tests, mocks, benchmarks & `pprof` profiling, linters (`golangci-lint`)
- **Security:** authentication & authorization, secrets management, OWASP basics
